# Day 11 커리큘럼 — 딥러닝 실전: 이미지를 보는 신경망 만들기

## 자리매김

- **Day 00(기존)** = 딥러닝 직관. Teachable Machine 노코드 체험 + 신경망·학습·CNN·전이학습을 그림으로. NVIDIA FDL 6부를 개념으로 압축한 날.
- **Day 11(신규)** = 그 짝인 실전. PyTorch로 신경망을 직접 짜고, 이미지로 훈련시키고, 데이터 증강·전이학습으로 내 데이터에 적용. Day 00에서 눈으로 본 것을 손으로 만든다.
- 관통 데이터셋: **MNIST(손글씨) → 내 소량 이미지(전이학습)**. Colab 무료 GPU(T4)에서 전부 실행.

## 챕터 구성 (docs/11 슬라이드 덱)

```
CH0  이어가기 — 직관에서 코드로
     Day00 복습 한 장 · 왜 이미지인가(픽셀=숫자) · 오늘 만들 것(내 이미지 분류기) 미리보기

CH1  신경망을 코드로
     텐서와 shape · 차원 읽는 법 · Flatten · nn.Module로 MLP 한 개
     학습 루프 네 줄(forward → loss → backward → step) · zero_grad의 이유
     손실 함수(크로스 엔트로피) · Adam · 에폭 · MNIST 첫 훈련과 평가

CH2  CNN — 이미지를 보는 층
     MLP가 이미지에 약한 이유(위치·크기 변화에 무너짐)
     합성곱 = 특징 검출 커널(엣지·텍스처) · 스트라이드 · 풀링 · 드롭아웃
     CNN 아키텍처(합성곱→풀링→밀집) · 특징 계층(엣지→텍스처→개체)
     같은 MNIST에 CNN 얹어 정확도 비교

CH3  데이터 증강 — 일반화를 사는 법
     train 정확도 > val 정확도(과적합 신호) 읽기
     증강 기법(반전·회전·줌·이동·밝기) · 왜 다양성이 일반화를 돕나
     증강 적용 전후 검증 정확도 비교

CH4  전이학습 — 남의 눈을 빌린다
     사전학습 모델(ImageNet에서 배운 것) · PyTorch Hub
     두 방식 — 특징 추출(freeze) vs 파인튜닝 · 더 일반적 층 ↔ 더 전문적 층
     내 소량 이미지에 적용 · 소량 데이터에서 왜 이게 실무 기본인가

CH5  마무리 — 저장과 다음
     모델 저장·로드 · Day 00 직관과 Day 11 코드의 연결
     '그 다음'(RNN·Transformer·GAN은 Day00에서 다리 놓음) 한 장 · 열하루의 지도
```

목표 분량 약 34~38장. 시각(합성곱·풀링·증강·전이학습)은 FDL 도식을 네이티브로 재현하거나 이미지로 임베드.

## 실습 노트북 (Colab GPU · PyTorch)

```
Lab 0  GPU 확인 (nvidia-smi · torch.cuda)
Lab 1  MNIST MLP — nn.Module 정의 → 학습 루프 → 평가 (첫 신경망)
Lab 2  MNIST CNN — 합성곱·풀링 얹고 MLP와 정확도 비교
Lab 3  데이터 증강 — transforms 적용 전후 과적합 완화 확인
Lab 4  전이학습 — 사전학습 ResNet freeze → 소량 이미지 분류
체크리스트
```

posco의 코드 우선 방식(개념 마크다운 + 실행 셀 1:1)을 따르고, Day 10에서 확립한 Colab GPU 실습 골격(zstd·Popen 없이 순수 PyTorch)을 재사용한다.

## 범위에서 잘라낼 것

- **FDL 1부(AI 역사·딥러닝이란)** — Day 00이 이미 다룸. 제외.
- **FDL 2부 개념(손실 곡선·활성화 함수 이론)** — Day 00에서 직관으로 봤으므로, Day 11에선 코드로 빠르게 통과.
- **FDL 6부(RNN·LSTM·오토인코더·GAN·강화학습)** — 폭이지 깊이가 아니고, Day 00이 RNN·Transformer→RAG 다리를 이미 놓음. CH5에서 '그 다음' 한 장으로만 언급.
- **모델 배포(FDL 4부 후반)** — 서빙은 Day 10이 담당. CH5에서 연결만.

## 확정이 필요한 결정

1. **프레임워크** — PyTorch 권장(posco 일치·실무 기본). FDL 원본은 Keras라, Keras 병기가 필요하면 Lab에 토글로.
2. **관통 데이터** — MNIST(가장 안전) + 전이학습용 소량 이미지. 도메인 특화(예: posco 양극재 이미지)로 바꿀지.
3. **깊이 vs 폭** — 위 안은 CNN·비전 실전에 집중(깊이). 대신 FDL 전체를 얕게 훑는 '요약형'도 가능.
